# Source, preservation and credits

## Authorship

Game programming and project assembly: **Shakhnazar Akhmer ([Eye172](https://github.com/Eye172))**, working solo. The learning projects are associated with the author's Kodland Unity / Unity Pro studies; this is not a claim that all techniques or third-party examples were invented independently.

Art, models, sound, fonts, Unity packages and imported sample content retain their original authorship. Each project has a `DEPENDENCIES.md` with the observed folders and package versions. Some original gameplay folders also include integration examples; existing source comments are preserved.

## Public contents

- Original gameplay-folder C# files and their `.meta` identifiers.
- Original scene descriptions and their `.meta` identifiers.
- Project version, build scene list, legacy input mappings and tag definitions.
- Original package manifest and lock file.
- Documentation and reviewed, genuine runtime captures.

The public source is an inspection archive. It deliberately does not bundle unreviewed third-party art libraries, personal editor settings, generated caches, service account configuration or analytics identifiers. Complete local project snapshots remain available to the owner for restoration.

## Preservation

Original source bytes are copied without reformatting, renaming classes, removing comments, changing encodings or altering old timestamps. The repository manifest records their SHA-256 values. Restoration tools and any compatibility patches belong to the 2026 restoration, separately from the historical source.

No blanket open-source license is applied to third-party content. This repository's public availability is not a relicensing of imported asset packs.
